# 前麦克风声路复核

复核日期：2026-11-06。本次保留左右各一个Ø3 mm外孔，以及原有两组独立导音槽/盖片；没有将孔数或几何通孔等同于拾音性能。

## 原厂资料能确认的内容

- [官方产品资料](https://www.waveshare.com/wiki/ESP32-P4-WIFI6-Touch-LCD-3.4C)列出板载SMD麦克风及回声消除用途。
- 产品页链接的[原理图与布局](sources/board_schematic.pdf)共两页：第一页MIC区域有MIC1、MIC2两路及对应音频网络；第二页Rev1.1布局在板下边左右标出MIC1、MIC2。两页均已渲染核对，相关图保存在本项目 `archive/microphone_review/`。
- 资料没有给出可直接用于冻结本外壳的声孔中心坐标、实际进声面、声口直径、软垫压缩量或安装公差。布局丝印和STEP外观不能替代电路板声孔的实物定位。

## 当前模型与结论

- 两个外孔Ø3 mm，每孔面积约7.07 mm²；各自通向3×3 mm独立声道。板端候选坐标x=±30、s=−43、n=12.3 mm，外口s=−61 mm，尚未实测。
- 现有名义折线路径长度为35.4 mm，包含两处转向。左右路径等长；本次检查零件没有堵塞声道，左右声路没有直接连通。
- 板端预留0.8 mm软垫、盖下0.2 mm密封垫。可制造的垫片空间不代表已证明软垫贴合真实麦克风声口或已经气密。
- 保留单孔方案，先确认真实麦克风声孔与进声方向，再决定是否缩短、减少弯折。不能凭布局比例移动接口，也不能靠增加外孔掩盖对接或密封问题。

## 实物冻结前

记录所用板版本、两侧声孔照片与中心坐标、进声面及可用密封面；试装软垫并检查无压住声孔、无左右或扬声器腔串音。比较安装外壳前后的录音和唤醒表现，覆盖安静环境及扬声器播放状态。35.4 mm声道的衰减、共振、风噪与AEC效果均保持未验证。
