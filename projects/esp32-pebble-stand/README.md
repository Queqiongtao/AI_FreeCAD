# ESP32-S3-Touch-AMOLED-1.75-B 鹅卵石桌面底座

参数化 3D 打印底座，适配 **ESP32-S3-Touch-AMOLED-1.75-B**。正面 Ø51 只露屏幕；底部、侧面、后面连续；后盖可拆，电池/开发板从后面维护。

![正面](output/preview_front.png)
![前右](output/preview_iso.png)

## 当前设计

- 屏幕与水平面 **50°**（离垂直 40°），桌面观看更自然。
- 整机高 **41.1 mm**，前后深 **44.5 mm**，最大直径 Ø51。
- 总重约 **94.4 g**（含 50 g 开发板 + 15 g 电池）。
- 前 / 后 / 侧倾覆角约 **36.8° / 29.9° / 42.0°**。
- 三个前壁通孔（顶部两个 MX1.25、底部 10-pin）真正贯通电池仓。
- 后盖完整闭合；6 点钟电池座关闭；左侧按键/右侧 USB-C 不开槽。
- **无电池托边**：前壳没有连接螺丝座的加强筋；电池由后盖/泡棉/双面胶固定。

## 运行

在 `projects/esp32-pebble-stand/` 目录：

**FreeCAD GUI 控制台：**

```python
exec(open(r"stand.py", encoding="utf-8").read())
```

**freecadcmd：**

```text
freecadcmd stand.py
```

脚本输出固定到 **`output/`**：

```text
front_shell.stl
rear_cover.stl
stand.step
stand.FCStd
```

改 `TILT_DEG` 只覆盖 `output/` 里的 STL/STEP/FCStd，不会新建版本文件夹。  \
`preview_*.png` 是静态渲染图，脚本不会重新生成；改角度后如需更新预览，单独重新渲染。  \
建议 FreeCAD **0.20 或更新**。

## 装配

1. 板子按螺丝位装入前壳：顶部 `(0,20.50)`，底部 `(±13.75,−14.70)`，M2×6 从仓内拧入。
2. 电池 36×26×8 放入电池仓；建议 36 mm 边沿 X 方向。
3. 后盖内面贴 1 mm 泡棉/双面胶，压住电池；或直接把电池胶在前壳仓底。
4. 电池/音响座从前壁两个 5×4 通孔进入电池仓；加强环内圈让位。
5. 10-pin 从前壁底部 14×4 通孔进入电池仓。
6. 左侧按键、右侧 USB-C 侧边外露，不开槽。
7. 后盖对正 **320/80/200**，推到底，顺时针 **25°** 到 **345/105/225**。
8. 如果旋转时后盖底部边缘蹭到前壳底板，向外抬 0.5 mm 再转；锁到位后底部齐平。

## 打印

- **前壳**：正面/屏幕面朝下，接缝朝上；三个通孔、加强环随外形打印，内部无托边，一般免支撑。
- **后盖**：导向颈朝下，半椭球朝上；完整闭合，无开孔；弹性后舌先手动弯 5–10 次。
- PETG，0.2 mm 层高，4 圈壁厚，4 层顶/底；卡爪/L 槽区域 100% 填充。
- 两个件都建议 5 mm brim；前壳 L 槽顶部约 3 mm 桥接，桥接不好时只在 L 槽内加局部支撑。
- 50° 后底部斜切面更斜；如果底部外缘下垂，局部加支撑，不要整件加。
- 先打后盖试卡口，再打前壳。

## 已验证

- 前壳 STL：**solid=True，components=1**，底面 z=0，6496.1 mm³，PETG 约 **8.25 g**
- 后盖 STL：**solid=True，components=1**，底面 z=0，15427.5 mm³，PETG 约 **19.59 g**
- 前壳/后盖自由状态 **common volume = 0.2361 mm³**，3 处，每处 0.0787 mm³，只在弹性舌/斜面
- STEP：两个有效实体（6505.3 / 15443.8 mm³）
- 三个孔：n=0.2/0.4/0.6 中心 `inside=False`，前壁中心 `inside=True`，电池仓中心 `inside=False`
- 电池 36×26×8 R3 放在 n=3.0–11.0：与前壳/后盖 **common=0**
- 旧托边位置（215°/270°/325°，r20.6，n=2.75）：**inside=False**，已完全删除
- 后盖：完整闭合；左侧/右侧无开槽
- 卡口锁紧 common=0.2361；转入过程底部边缘有轻微扫掠干涉（29 mm³ 量级），轻抬即可

## 已知取舍

- 电池没有前壳托边，靠后盖/泡棉/双面胶固定；如果实际电池松动，加 1 mm 泡棉或双面胶。需要打印定位的话，可以在后盖内面加浅定位框。
- 左侧按键、右侧 USB-C 的参考体与前壳侧壁有重叠；按你的要求不开槽。实际装板后如果 USB/按键被侧壁挡住，再单独加浅让位。
- 后盖转入时底部边缘会扫到前壳底板，轻抬 0.5 mm 再转；不影响锁紧后的配合。
- 弹性后舌是 printed living spring；先打后盖试锁，裂了可退回旧垫片方案。
- 50° 比早期 65° 版本更深（44.5 mm vs 37.5 mm），桌面占深增加，但重心更低、倾覆角更大。
