# ESP32-S3-Touch-AMOLED-1.75-B 鹅卵石桌面底座

参数化 3D 打印底座，适配 **ESP32-S3-Touch-AMOLED-1.75-B**。正面 Ø51 只露屏幕；后盖可拆；整个桌面接触面在后盖上。

![正面](output/preview_front.png)
![前右](output/preview_iso.png)

## 当前 vA（2026-10-29）

- 前盖 **100% 不削**；整体抬高，`BOTTOM_GAP` 2.0 → **7.2 mm**。
- 整机高约 **46.0 mm**；前脸最低点约 **6.2 mm**，前盖最低点（电池笼）约 **3.2 mm**，都不碰桌面。
- 后盖中心开电池孔，底部保留 5 mm 外圈（实际桌面接触为外侧月牙面，见下）；电池最后从底部装入前盖电池笼。
- 螺纹 **2.0 圈 × 3 mm 螺距**，净转 **720° = 0°**；屏幕正位开始、正位到底。
- 螺纹真正咬合：前盖小径 r22.3 / 大径 r23.0；后盖小径 r22.8 / 槽底 r23.6；径向 0.2 mm；末端 0.05 mm 防松。
- 牙顶/牙根做 **0.2 mm 倒角**，起牙前 0.2 圈斜坡，末端 0.25 圈收牙；螺纹不再是尖角。
- 旋合扫描 −10°…−720° 全程 common=0；终位防松 common=0.7156 mm³。
- 电池/前盖/后盖 common=0；电池最低 z≈9.7 mm。
- 总重约 **92.5 g**；前/后/侧倾覆角约 **18.4° / 18.0° / 21.9°**。
- **已知限制**：后盖底部是斜切壳体，中心开孔后实际桌面接触是**外侧月牙面**（约 20×17 mm），不是完整 5 mm 圆环。要做完整圆环需要加第三个底环零件，或改后盖底部结构；当前两件版先保留这个月牙接触面。

- 屏幕与水平面 **50°**（离垂直 40°）。

- 前 / 后 / 侧倾覆角约 **35.1° / 38.0° / 40.0°**。
- **前脸/外圈完整保留**；前盖前部最低点 z≈1.03，离桌面约 1 mm；后盖最低点 z=0，是唯一桌面接触面。

### 1. 前薄盖

- 前脸 Ø51；可见外圈只有约 2 mm，后面是短螺纹颈。
- 3 颗板螺丝、三个前壁通孔、两个加强环都保留。
- 外螺纹 Ø46，n≈3–7.8；螺纹完全藏进后盖前口。
- 前盖内部带一个 **电池笼**：r21.3，n≈0.5–12，电池 36×26×8 R3 放在里面。
- **前脸/外圈完整保留**；前部最低点 z≈1.03，离桌面约 1 mm，不接触桌面。
- 只有内部 n≥2.01、会跟后盖底板相交的部分被局部清到 z=2.25；后盖底板顶面 z=2，留 0.25 mm，不再有内部底部支撑面。
- 前盖 **z=2.25 以上保留约 5 mm 高的完整圆带**；后盖前口是完整圆孔，圆带在里面旋转导向，底部不需要开窗。
- 前盖接缝肩面 n=2 保留，作为螺纹轴向停止。

### 2. 后整机身

- 前口内螺纹 Ø46.4，n≈3–7.8；前口盖住前盖侧面。
- 整个鹅卵石外壳 + 后穹顶；外轮廓最大 Ø50.2。
- 底部 **z=0–2 整块实体底，完整封闭、无开窗**，是最低点，也是唯一桌面接触面。
- 后盖内部是一个大腔，清空前盖电池笼和电池。
- 拆后盖时，电池和板子留在前盖上；电池线不随螺纹旋转。

### 3. 螺纹

- 单头、右旋、大螺纹；前盖外螺纹，后盖内螺纹。
- 螺距 3 mm，牙深 0.7 mm，约 1.6 圈 / 4.8 mm 啮合。
- 螺纹完全藏在后盖前口内，外轮廓仍是 Ø50.2 接缝。
- 末段 0.25 圈有 0.05–0.1 mm 过盈，用于防松。
- 拧到底时，前盖内部底面离后盖底板 0.25 mm；前盖前部最低点离桌面约 1 mm；前盖只靠螺纹和接缝肩面定位。

### 4. 电池笼

- 电池笼在前盖内部，隐藏在后盖里；后盖旋转时电池不动。
- 电池 36×26×8 R3，n=3–11；前盖/后盖 common=0。
- 电池笼内径 r21.3；后盖腔 r23.2，留 0.9 mm 旋转间隙。
- 没有电池托边；电池用双面胶/泡棉固定在电池笼里。
- 电池线从前盖三个通孔走到板子；拆后盖时电池线不需要跟着转。

## 装配

1. 板子按螺丝位装入前盖：顶部 `(0,20.50)`，底部 `(±13.75,−14.70)`，M2×6 从电池笼侧拧入。
2. 电池 36×26×8 放进前盖电池笼，用双面胶/泡棉固定；电池线从前盖三个通孔走到板子。
3. 电池/音响座从前壁两个 5×4 通孔进入电池笼；加强环内圈让位。
4. 10-pin 从前壁底部 14×4 通孔进入电池笼。
5. 左侧按键、右侧 USB-C 侧边外露，不开槽。
6. 后盖对正螺纹，推入到螺纹啮合，再顺时针（从后盖外侧看）旋转约 **1.6 圈**。
7. 拧到底时，前盖内部底面离后盖底板 0.25 mm；前盖前部最低点离桌面约 1 mm；前盖只靠螺纹和接缝肩面定位，后盖底板接触桌面。

## 打印

- **前盖**：正面/屏幕面朝下；外螺纹和电池笼在顶部；薄件，基本免支撑。
- **后盖**：**底面朝下**；z=0 底部平板在热床；内螺纹/前口/电池腔朝上；外层鹅卵石向上收，支撑最少。
- PETG，0.2 mm 层高，4 圈壁厚，4 层顶/底；螺纹/前口区域 100% 填充。
- 两个件都建议 5 mm brim。
- 螺纹起始处如果轻微下垂，局部修一下或用小刀轻刮。
- 不单独打螺纹试环；先打整件，手感不对再调参数。

## 已知取舍

- 电池笼做在前盖内部、藏后盖里，而不是直接做在旋转的后盖上；否则后盖旋 1.6 圈会把电池线拧断。拆后盖时电池/板子留在前盖，电池从后面可以直接取出。
- 电池没有托边，必须用双面胶/泡棉固定在电池笼内。
- 前盖可见厚度 8 mm；内部电池笼到 n=12，隐藏在后盖大腔里。
- 螺纹需要约 1.6 圈；比原来的 25° 卡口慢。
- 末段防松过盈 0.05–0.1 mm；如果实际太紧，调 `THREAD_END_CREST_R` 或螺纹相位；太松则加大过盈。
- 后盖底部是整块 z=0–2 实体；前盖前脸/外圈完整，前部最低点 z≈1.03，离桌面约 1 mm；前盖内部底面 z=2.25，离后盖底板 0.25 mm，不接触桌面，也不坐在后盖底板上。
- 螺纹是打印件，牙距 3 mm、牙深 0.7 mm；不同打印机需要微调间隙。
- 左侧按键、右侧 USB-C 的参考体与前盖侧壁有重叠；按你的要求不开槽。实际装板后如果被挡住，再单独加浅让位。

## 参数修改

`stand.py` 顶部：

- `TILT_DEG`：屏幕与水平面夹角，当前 50°
- `CAP_SEAM_N` / `CAP_NECK_N`：前盖接缝/螺纹颈位置
- `CRADLE_N` / `POCKET_R` / `CRADLE_R_OUT`：电池笼
- `THREAD_PITCH` / `THREAD_TURNS` / `THREAD_START_N`：螺纹
- `THREAD_ROOT_R` / `THREAD_CREST_R`：前盖外螺纹
- `REAR_CAVITY_R` / `REAR_CAVITY_N` / `REAR_BACK_N`：后盖腔/后穹顶
- `THREAD_END_CREST_R` / `THREAD_START_ANGLE_DEG`：防松/相位
- `SCREWS_2D`、`CONN_*`、`HEADER_*`：板子/开口

## 结论

- 前盖只做薄前脸、板螺丝、三个通孔和短螺纹；可见厚度约 8 mm。
- 后盖是整机身、内螺纹和唯一桌面接触面；前盖前部最低点 z≈1.03，离桌面约 1 mm；前盖内部底面 z=2.25，离后盖底板 0.25 mm。
- 电池在前盖电池笼里，隐藏在后盖内；后盖旋转时电池不动，电池线不拧。
- 总重 89.3 g，前/后/侧倾覆角约 **35.1° / 38.0° / 40.0°**。
